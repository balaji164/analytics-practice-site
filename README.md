# Nexora Analytics Practice Site

A fictional SaaS + ecommerce website built for hands-on Google Tag Manager and GA4 practice.

## GTM
Every HTML page includes the GTM container snippet for **GTM-PJCNRHP6** in both `<head>` and immediately after `<body>`.

## GA4
Use the Google tag in GTM with measurement ID **G-PTBB8LWCZY**.

## Journeys
- SaaS: home → product → pricing → signup → checkout → success
- Ecommerce: home → category → product → cart → checkout → order success
- Lead: contact/sales form → thank-you
- Video: HTML5 product demo on the homepage

No conversion tracking tags are preconfigured in GTM by this site build; the goal is to implement them yourself during practice.
